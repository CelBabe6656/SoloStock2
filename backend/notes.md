## How to Run the Backend

1. Open the notebook in Google Colab  
2. Run all cells from top to bottom  
3. View outputs:
   - Sample transactions
   - GL report
   - Tax summary
   - Vehicle km summary
4. Save updates back to GitHub using:
   **File → Save a copy in GitHub**
