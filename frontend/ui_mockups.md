# UI Mockups

These mockups describe the intended user interface.

---

## 1. Receipt Upload Screen

- Large “Upload Receipt” button
- Dropdown:
  - PAYG
  - Sole Trader
  - Both
- Slider:
  - Business %
  - PAYG %
  - Personal %
- Preview of extracted data
- “Confirm” button

---

## 2. Dashboard

Tiles:
- Total income
- Total expenses
- GST collected
- GST paid
- Tax payable
- Safe-to-spend balance

Graph:
- Monthly expenses by GL category

---

## 3. Vehicle Logbook

- “Start Trip” button
- Enter km
- Select:
  - PAYG
  - Business
- Logbook % applied automatically
- Warning banner at 4,500 km

---

## 4. General Ledger Report

Table with filters:
- Date
- Vendor
- GL Code
- ATO Label
- Source
- GST
- Confidence score
- Apportionment %

---

## 5. Settings

- Edit GL names
- Edit business details
- Edit industry for benchmark engine
